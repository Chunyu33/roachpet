# Changelog

## 1.0.0 - 2026-08-28

First public release of RoachPet, a portable Windows desktop cockroach pet.

- Transparent, borderless, always-on-top desktop pet.
- Smooth roaming with idle pauses, bursts, edge bouncing, and click-to-flee.
- Supports 1–10 cockroaches, size presets, Chinese settings, and tray controls.
- Time-based Cantonese hover dialogue.
- Portable ZIP package for Windows 10 or later; WebView2 Runtime is required.
- No automatic updates.
